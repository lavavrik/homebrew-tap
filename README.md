# lavavrik/tap

Homebrew formulae for [puppy](https://github.com/lavavrik/puppy).

```sh
brew install lavavrik/tap/puppy
brew services start puppy   # optional: run the daemon as a login service
```

`Formula/puppy.rb` is written by puppy's release workflow
(`scripts/homebrew-formula.sh`) on every stable release; don't edit it by hand.
